## 현재 버전 검사
- Vitest 6파일 36개 전체 통과, 135.0초. 후속 라이벌 실제 로스터 연결 및 관심 보존 수정 후 관련 15개 재실행 통과.
- TypeScript 및 프로덕션 빌드 통과.
- Playwright 4시나리오 × PC/모바일 크기 Chromium = 8개 통과, 최종 31.5초.
- 실제 iPhone Safari/WebKit·홈 화면 설치는 미검증이다.

### 신규 규칙 검사
동갑/동포지션/다른 학교 라이벌의 20년 ID·이름·나이·로스터 수 보존과 은퇴. 천재 훈련량 정확히 1.7배, 럭키 정확히 10배(상한 도달 전), 피로 80에서 효율 36%, 휴양 회복과 지출/잔액 부족 거절. 7일 일정의 토요일 정지→저장/복원→동일 결과→일요일 처리→주간 성장노트 한 번 기록. 실전파 능력 ×1.3의 경기 한정 적용, 깨달음의 영구 반영 한 번 처리. 10,000회씩 깨달음 3%/9% 표본 비율 허용 오차 검사. 관심 구단 제안 보장, 13일째 유효/14일째 만료, 비시즌 2주 진행과 재구직. v3 선수/기록/진행 중 경기 보존 migration.

### 브라우저 시나리오
1. 생성·주간 일정 변경·실시간 행동·Canvas 움직임·성장노트·라이벌 화면·최근 일정 기억·경기 중 새로고침·슬롯·내보내기/복원.
2. 프로덕션 서비스워커 캐시 후 오프라인 새로고침·7일 일정·경기·성장 저장.
3. 손상시킨 기본 슬롯의 백업 복원.
4. 고교 2시즌·라이벌 나이 증가·제안 확인·비시즌 2주 진행으로 만료·재구직·협상·프로 계약과 다음 경기.

### 경기 밸런스
2,000 시드 경기: 합산 평균 3.7975골, 25.2625슈팅, 0:0 39회, 최고 합산 11골. 홈/원정 평균 1.675/2.1225. 포지션 평균 GK6.595/LB6.705/CB6.451/RB6.610/CM6.666/LW7.021/ST7.023/RW6.916, 최대 격차 0.572. 기존 목표 범위 통과. 이 표본은 기본 능력 경기이며 모든 성장 단계·특성 조합의 장기 밸런스를 보장하지 않는다.

미드필더 전진 패스 고정 정책 200경기: 성공 1,003, 키패스43, xA5.281, 도움4. 이전 0.2.1의 키패스86/도움9보다 줄었으나 최초 문제가 있던 버전(7/0)보다 개선된 상태다. 유동적 수비 마킹으로 전체 공격 성공도도 변했다. 사용자 체감은 추가 플레이를 통해 조정할 항목이다.

### 발견·수정
손상된 테스트 Chromium 바이너리를 원본 패키지로 재구성해 실행 환경 복구. 주간 일정이 경기 화면으로 자동 전환되지 않는 오류 수정. 경기 중 일정 화면의 날짜 기준을 시작일로 고정. 고교 초반 관심 구단을 졸업 때까지 보존. 직접 상대 라이벌이 벤치일 때 별도 가상 경기를 만들지 않음. 교체 아웃한 라이벌의 통계 스냅샷 보존. 라이벌 경기는 실제 양팀 선발 로스터의 능력을 사용. 시각 검사는 1배속에서 행동 전후 Canvas 변화를 확인해 빠른 진행의 중간 프레임 누락을 피했다.

### 남은 범위
라이벌의 별도 컵 대진, 전체 NPC 급여/이적료 회계, 모든 특성의 수십 시즌 사용자 플레이 밸런스, 다중 탭 저장 동시 쓰기, 실제 Safari 기기 검증은 남아 있다. 기존 30시즌 세계 테스트는 경량 세계 일정/예산 정합성 검사이며 30년 전체 사용자 UI 검사가 아니다. 압축 시즌에서 다음 시즌으로 넘어갈 때 건너뛴 비시즌에는 일일 훈련을 소급 적용하지 않는다.

## 2026-10-16: 패스 후 찬스 연결 회귀
이전 평점 보정만으로 해결되지 않은 사용자 패스의 실제 공격 연결을 검사했다. 시드 1~200, 사용자 CM 능력 60, 상대 60, 동료 생성 기본 46, 공을 받을 때마다 전진 패스, 기본 오프볼 지시의 고정 정책이다. 동일 seed라도 정책 변경 후 전체 난수 소비 경로는 달라지므로 개별 경기의 직접 인과 비교를 의미하지 않는다.

기존 엔진은 패스 비행 때 기본 위치로 복귀하고 CM이 전개를 뒤따르지 않아 직접 찬스가 적었다. 공격 형태 유지·CM 지원·수신 기회 고려·좋은 기회에서 빠른 판단을 수정했다. 위 표는 제한된 전진 패스 정책의 회귀 표본이며 모든 경기에서 도움을 보장하지 않는다. 실제 사용자 저장은 제공받지 않았다.

추가 회귀: 양 진영 패스 비행 중 CM의 전진 지원, 명확한 슈팅 위치 수신 후 다음 tick 판단. 브라우저 검사는 빠른 리턴 패스로 잠깐 표시되는 비소유 화면을 놓치지 않도록 일시정지→패스→상태 확인→재개 순서로 변경했다.

초기 수정은 2,000경기 평균 5.039골로 목표를 초과해 출시하지 않았다. 후속 조정에서 빠른 판단 기준을 22%로 제한하고 수비 차단 및 기본 득점 계수를 보정했다. CM 한 명만 뒤에 남기는 실험은 개선되지 않아 채택하지 않았다.
