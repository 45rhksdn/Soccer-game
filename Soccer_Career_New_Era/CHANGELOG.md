# Changelog

## 0.3.1 — 2026-10-16 (안정화 패치)

0.3.0 ZIP 스냅샷 기준의 버그 수정·정리. 게임 규칙, 밸런스 수치, 저장 스키마(v4)는 바꾸지 않았다. 기존 세이브는 그대로 읽힌다.

### 수정
- **라이벌 관심 구단 누락** (`development.ts` `scoutInterest`): 사용자에게 맞는 구단이 없는 주에 함수가 `return`으로 끝나 라이벌 스카우트와 `interestedClubIds` 동기화가 건너뛰어졌다. `continue`로 수정.
- **백업 손상 전파** (`storage.ts` `save`): 현재 슬롯이 손상된 상태에서 저장하면 정상 백업이 손상 데이터로 덮였다. 이제 읽을 수 있는 슬롯만 백업으로 옮긴다(`isRestorableSave`).
- **백업이 사실상 현재 저장과 동일** (`storage.ts` `save`): 5초 자동 저장이 변경 여부와 관계없이 슬롯→백업을 회전시켜, 백업이 몇 초 전 상태와 같아졌다. 내용이 같으면 슬롯·백업을 쓰지 않아 백업이 “마지막으로 달랐던 저장”을 유지한다. 불필요한 쓰기도 줄어든다.
- **저장 검증 보강** (`storage.ts` `validate`): 특성 목록을 하드코딩 대신 `TRAITS`에서 읽고, 라이벌 특성도 검증한다.
- **경기 중 저장 대상 슬롯** (`App.tsx`): 판단 시점/종료 시 저장이 렌더 시점의 슬롯 대신 현재 슬롯 ref를 사용한다(다른 자동 저장 경로와 동일).
- **가져오기 취소 후 같은 파일 재선택 불가** (`App.tsx`): 확인창을 취소하면 파일 입력이 초기화되지 않아 같은 파일을 다시 고를 수 없었다.

### 정리
- 사용되지 않는 0.2 훈련 화면 컴포넌트 `TrainingCards`와 미사용 import 제거(`App.tsx`, `career.ts`, `development.ts`, `WorldPanels.tsx`).
- `career.ts`의 `train()`은 테스트가 사용하므로 유지하되 레거시임을 주석으로 명시.

### 추가
- `tests/fixes.test.ts`: 위 수정의 회귀 테스트 3개(원본 코드에서는 실패, 수정 후 통과 확인).
- `.github/workflows/ci.yml`(저장소 루트): push/PR마다 `Soccer_Career_New_Era/`에서 `npm ci` → `npm run build` → `npm test`.

### 확인했지만 바꾸지 않은 것 (결정 필요)
- 주간 일정(`applyDaily`)에는 훈련 부상 판정이 없다. 훈련 부상은 레거시 `train()`에만 있다. 유리몸(훈련 부상 ×1.5) 구현 전에 훈련 부상 규칙을 정해야 한다.
- 학교 데이터의 `boost`(패스/스피드/수비)는 생성 화면에 표시되지만 게임에 아무 효과가 없다.
- NPC 480명은 특성·부상이 없다. 학교는 `school` 0~2 인덱스가 저장 검증, 라이벌 학교 계산(`%3`), 구단 ID(`'c'+school`), 라이벌 화면(`clubs[r.school]`)에 묶여 있다.
