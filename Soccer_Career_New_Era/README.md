# Soccer Career — New Era

독립적인 한국어 싱글플레이 축구선수 커리어 웹게임. **0.9.0 / 11개 프로 리그 · 전략적 이적 · 감독 미션 · 시그니처 도전** (0.5: 깨달음·럭키 분리 · 32세 전성기 · 장비 · 은퇴 누적 보상 · NPC 부상) (0.4: 다중 특성 · 실제 고교 발굴 · 선수 변경하기).
원작의 소스·그래픽을 사용하지 않았으며, 원작의 확인되지 않은 기능을 사실로 주장하지 않는다. 학교명·지역만 실제이며(공개 대회 자료로 축구부 운영 확인), 선수·감독·구단·상대는 모두 가상이다.

다음 담당자(ChatGPT Work / Claude)는 먼저 [HANDOFF.md](HANDOFF.md)를 읽는다.

## 플레이

1. **새로운 커리어 시작** → 두 가지 방법 중 선택한다.
   - **실제 고교에서 발굴**(기본): 시·도 지도 또는 검색으로 실제 축구부가 있는 고등학교를 고르면 가상의 후보 6명이 나온다. 나이·포지션·체격·능력치 20종·잠재력 추정·특성을 비교하고 한 명을 골라 시작한다. **새 후보 목록 생성**으로 다른 후보를 볼 수 있으며, 학교별 목록은 새로고침·재접속 후에도 같다.
   - **직접 만들기**: 기존처럼 이름·포지션·체격을 입력하고 가상 고교 3곳 중 하나에 입단한다.
2. 선수는 34종 중 특성을 **0~3개** 가진다(없을 수도 있음). 긍정 특성은 초록색 `+`, 부정 특성은 빨간색 `−` 아이콘으로 표시된다. 라이벌과 NPC 1,440개 선수단 자리도 같은 규칙의 특성을 가진다.
3. 커리어 홈의 **오늘의 일정 진행**에서 하루씩 진행한다. 훈련 아이콘(공격·속력·패스·드리블·수비·책 읽기·휴식·휴양)을 누르면 하루가 지나고 해당 능력치가 성장하며, 훈련 럭키(나이별 20세 이하 4.5%·21~24세 3.5%·25~32세 2.5%·33세 이상 0.5%, 행운아 ×3·불운 ×⅓)가 발동하면 그날 성장 ×10. 경기 중 행동마다 깨달음(0.5%, 행운아 1.5%)으로 관련 능력 +1. 둘 다 발동하면 팝업이 뜨고, 뉴스에는 수치 없이 `훈련 중 무언가를 느꼈다!` / `경기 중에 깨달음을 얻었다!`로만 나온다(정확한 수치는 성장노트). 토요일에는 훈련 대신 **오늘은 경기가 있는 날입니다** 화면에서 경기를 진행하고, 결과 반영 후 일요일 일정을 고른다. 일정은 **하루 단위로만** 진행한다(메뉴의 **오늘의 일정** 화면도 같은 기능). 7일 일괄 계획 화면은 0.4에서 제거했다. 비시즌에는 남은 요일을 채우지 않아도 다음 시즌을 시작할 수 있다. 피로가 60% 이상인 날의 훈련은 부상 위험(기본 2%)이 있다.
4. 시즌 마지막 경기 결과를 반영하면 **시즌 결산** 화면(순위·출전·골·도움·평균 평점)으로 자동 이동한다.
5. **선수 변경하기**에서 최대 3명의 선수 커리어를 슬롯별로 따로 보관하고 전환한다. 전환 전 현재 선수를 먼저 저장한다. 이미 선수가 있는 슬롯에 새 선수를 시작하면 확인 후 교체되며, 기존 선수는 **교체 전 선수**로 보관되어 복원할 수 있다.
6. 이적 · 계약 화면에서 목표 구단, 우선순위, 경쟁자, 육성 환경을 비교하고 계약 협상 또는 임대를 선택한다. 제안은 14일 후 만료된다.
7. **성장과 노화(0.5)**: 32세 무렵이 최전성기. 나이가 들수록 훈련 성장이 느려지고 33세부터 스피드·가속도·체력 순으로 감퇴한다. 라이벌·NPC도 같은 모델.
8. **장비(0.5)**: 내 선수 화면에서 축구화·트레이닝 웨어·보조 장비를 사고 장착한다. 보너스는 경기에만 더해지고 기본 능력치는 따로 성장한다(능력치 옆 `+2` 표시).
9. **은퇴 누적 보상(0.5)**: 선수가 은퇴할 때마다(선수당 1회, 세 슬롯 공용) 새 선수 후보의 잠재력 최대 상한 +1(최대 +6). 선수 변경하기 화면 상단에 표시. 같은 화면에서 **이 선수 삭제**로 슬롯을 비울 수 있다(교체 전 선수·은퇴 기록은 유지).
10. **경기 중 수비(0.6)**: 실시간 경기에서 상대가 공을 몰고 내 근처로 오면 스탠딩 태클·슬라이딩 태클·압박·예측 수비 중에서 고른다. 수비에 성공하면 평점에 조금 반영된다. 이적 제안은 현재 포지션 능력에 맞는 구단에서만 온다.

휴양은 게임 내 5만원, 초기 생활비 100만원, 고교 재학 중 주 2만원. 실제 결제는 없다. 능력치 최대 100.

## 개발 실행

Node.js 22 이상 권장. 별도 API 키·DB 서버·유료 API가 필요 없다. 저장소에서는 이 폴더(`Soccer_Career_New_Era/`)가 프로젝트 루트다.

```sh
npm ci
npm run dev
```

## 빌드 및 배포

```sh
npm run build
npx vite preview --host 127.0.0.1 --port 4173
```

`dist/` 전체를 HTTPS 정적 호스팅에 배포한다. 상대경로 빌드로 하위 경로 배포도 가능하다. 사이트 주소(origin)가 바뀌면 IndexedDB가 분리되므로 JSON으로 옮긴다. PWA는 프로덕션 빌드에서만 활성화된다.

**배포 주의:** 운영 사이트(Work 배포)에는 이 저장소에 없는 최신 변경이 있을 수 있다. 이 브랜치를 운영 사이트에 덮어쓰기 전에 반드시 최신 Work 소스와 비교·병합한다(HANDOFF.md 참고).

## 테스트

```sh
npm test                                   # Vitest: 단위·회귀·밸런스·장기 커리어·은퇴 통합 (125개)
npx tsx scripts/long-sim.ts 6 20           # 장기 성장 시뮬레이션(6명 × 20시즌, 약 5분)
npx playwright install chromium
npm run test:e2e                           # PC + iPhone 화면 크기 Chromium
npm run build && PWA_TEST=1 npm run test:e2e   # 프로덕션 빌드 + 오프라인
WEBKIT=1 npx playwright test --project=iphone-webkit   # 선택: Safari 엔진(WebKit)
```

**iPhone 화면 크기 Chromium·WebKit 에뮬레이션은 실제 iPhone Safari 검증이 아니다.** 실제 기기 Safari·홈 화면 설치는 아직 테스트하지 않았다. GitHub Actions(`.github/workflows/ci.yml`)가 push/PR마다 빌드·단위·브라우저 테스트를 실행한다.

## 구조

- `src/engine.ts`: DOM 없는 결정론적 축구 엔진
- `src/career.ts`: 생성·훈련·성장·선발·경기 결과·시즌 전환 (`CareerPreset`, `schoolRef`)
- `src/world.ts`: 24구단/480선수(특성 포함), 리그, 감독, 이적, 계약, 신인/노화
- `src/development.ts`: 7일 일정·훈련 부상·라이벌·뉴스·관심 구단
- `src/traits.ts`: **특성 데이터 표와 효과 계층**(사용자·라이벌·NPC 공통), 깨달음·럭키 확률 상수
- `src/aging.ts`: **0.5 나이·성장·노화 모델**(주인공·라이벌·NPC 공통)
- `src/equipment.ts`: **0.5 장비**(기본 능력치와 보너스 분리), `src/legacy.ts`: **0.5 은퇴 누적 보상**
- `src/schools.ts`: **실제 고교 축구부 목록(73개교, 17개 시·도)과 출처**
- `src/scouting.ts`: **재현 가능한 가상 후보 생성**과 후보 → 커리어 시작

## 데이터와 복구

저장은 기기/브라우저별로 독립적이다. 슬롯 3개(`slot1..3`)와 각 슬롯의 직전 백업(`backup1..3`), 교체 전 선수(`archive1..3`), 스카우트 상태(`scouting`)를 IndexedDB에 저장한다. 직전 백업은 내용이 달라질 때만 갱신되고, 읽을 수 없는 슬롯은 백업으로 옮기지 않는다. 브라우저 데이터 삭제 전에는 JSON으로 내보낸다. 계정 공통 은퇴 기록은 `legacy` 키에 따로 둔다. 저장 형식은 **v6**이며 v1~v5 저장은 자동 변환된다(기존 특성·능력치·기록 보존). 체크섬은 우발적 손상 검출용이며 보안 서명이 아니다.
